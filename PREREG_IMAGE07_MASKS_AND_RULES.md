# Preregistration: image07 disjoint masks and generic best64 mutations

Date: 2026-09-05. Committed before testing either target family. Both use the
validated MD5 XOR-fold target seed `0f58d719`; every fold collision still
requires two successful ordinary steghide extractions.

## Stage F — disjoint bounded character masks

Enumerate these four families, in the listed alphabet order and length order:

1. Every string of lengths 1–4 over printable ASCII bytes `0x20..0x7e`:
   **82,317,120** candidates.
2. Every length-5 string over
   `abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789`:
   **916,132,832** candidates.
3. Every length-6 string over `abcdefghijklmnopqrstuvwxyz0123456789`:
   **2,176,782,336** candidates.
4. Every length-7 string over `abcdefghijklmnopqrstuvwxyz`:
   **8,031,810,176** candidates.

Total raw candidates: **11,207,042,464**. Families are disjoint by length except
that masks use different lengths, so there is no overlap. No preferred prefixes,
semantic insertions, or adaptive extension.

Control: run the same odometer/MD5-fold implementation over alphabet `abc123`,
lengths 1–6, against registered key `a1b2c3`; compare first/middle/last C folds
with Python and require the exact key to be returned.

## Stage G — generic installed best64 mutations

Freeze these non-puzzle-specific sources:

1. `/snap/john-the-ripper/current/bin/password.lst`, excluding `#!comment:`

2. all printable-ASCII nonempty items returned by
   `wordfreq.top_n_list('en', 500000)`.

Apply every non-comment, nonblank rule in the installed file
`/usr/share/hashcat/rules/best64.rule` (currently 77 such lines; file SHA-256
`96ec12f5d080bbe8a743fc58a33bf85defee5258797ce1f3b6894a0448b223c3`)
with installed Hashcat 6.2.6. Preserve generated byte strings as emitted; do not
add target-specific words or extra rules. Duplicate outputs may be tested but
must be counted.

Control: source line `planet`, same rule file, registered generated target
`planet1`. The fold filter must return it and independent Python must agree.

## Decision rule and controls

Record source/base hashes, exact generated counts, throughput, every fold
collision, and extraction result. The raw Stage-F null expectation is
`11,207,042,464 / 2^32 = 2.6093` fold collisions; Stage G's expectation is its
actual generated count divided by `2^32`. Collisions and uniqueness are not
clues. Only duplicate successful, hash-identical extraction recovers the key.
A miss closes only these exact families; no post-hoc mutation or mask extension.

No live-site request or submission is involved.

## Decision

Both registered families are **killed**. The three mask collisions were random
and cryptographically rejected; generic best64 mutations produced none. No mask
or rule was expanded after the results.
